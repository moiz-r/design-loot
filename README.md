# design-loot

A list of cool design websites, UI resources, and component libraries I find on the web.

## Sections

| Section | What is inside |
|---|---|
| [Inspiration](inspiration.md) | Cool websites to look at for ideas |
| [UI libraries](ui-libraries.md) | UI parts you drop into code: buttons, toasts, animations |
| [Component libraries](component-libraries.md) | Full component sets and design systems |
| [AI tools](ai-tools.md) | DESIGN.md generators and other AI tools |
| [Palettes & tokens](palettes.md) | Color palettes, design tokens, and UI states |
| [Queue](queue.md) | Raw finds, quick capture from mobile |

## How entries work

**Quick find on mobile?** Add a raw line to [queue.md](queue.md). No tables needed. Triage later.

Each section is a table with 3 columns:

| Name | What it is | Why it is cool |
|---|---|---|

Rules:
- Keep notes short: 1–3 sentences, simple words.
- One entry per line. No extra files per entry.
